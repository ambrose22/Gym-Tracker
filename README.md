# Block 1 — Gym Workout Tracker

A PWA (Progressive Web App) for tracking a 4-week hypertrophy training block. Built with React + Vite, works fully offline once installed.

## What's in here

```
├── public/                 # Static files served as-is
│   ├── favicon.svg         # Browser tab icon (B1 logo)
│   ├── pwa-192x192.png     # PWA icon (small) — generated
│   └── pwa-512x512.png     # PWA icon (large) — generated
│
├── src/
│   ├── main.jsx            # Entry point — mounts the React app
│   ├── App.jsx             # The entire tracker UI and logic
│   └── storage.js          # Saves/loads data using localStorage
│
├── scripts/
│   └── generate-icons.js   # Generates the PWA PNG icons
│
├── block1-tracker.jsx      # Original artifact source (reference only)
├── index.html              # HTML shell the app loads into
├── vite.config.js          # Build config + PWA/service-worker setup
├── package.json            # Dependencies and scripts
└── README.md               # You are here
```

### How the pieces fit together

- **App.jsx** is the whole tracker — programme data, exercise cards, weekly overview, the "how did it feel?" section, and the coach chat. It's a straight port of the original Claude artifact with three changes:
  1. Uses `storage.js` instead of `window.storage` (same async interface, backed by localStorage)
  2. The coach chat POSTs to `/api/coach` instead of directly to api.anthropic.com
  3. Export/import data buttons in a Settings section at the bottom

- **storage.js** wraps `localStorage` in the same `get(key)` / `set(key, value)` async interface the original used, so the component logic didn't need to change.

- **vite-plugin-pwa** (configured in `vite.config.js`) generates a service worker that caches the entire app for offline use. The only thing that needs internet is the coach chat.

- **PWA icons** are generated by `scripts/generate-icons.js` — a Node script that creates PNG files (dark background with "B1" in amber) using raw byte manipulation, no image libraries needed.

## Running locally

```bash
# 1. Install dependencies
npm install

# 2. Generate the PWA icons (one-time)
node scripts/generate-icons.js

# 3. Start the dev server
npm run dev
```

This opens at **http://localhost:5173**. Your workout data saves to your browser's localStorage.

## Phase 2 (coming next)

Phase 2 adds a serverless backend deployed on Vercel:

- **API proxy** (`/api/coach`) — a Vercel serverless function that sits between the app and the Anthropic API. Your API key stays on the server, never in the browser.
- **App key auth** — a simple shared secret so only you can use the coach endpoint.
- The app itself gets deployed to Vercel too, so you can use it from your phone without running a dev server.

## Data safety

All workout data lives in your browser's `localStorage`. Use **Settings → Export data** to download a JSON backup anytime. You can restore from a backup with **Import data**.

The coach chat history is also stored locally. Nothing is sent to any server except the coach messages (and those only go to the Anthropic API through the proxy).
